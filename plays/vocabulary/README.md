# Vocabulary

打开首页的 Vocabulary，登录 Owner 后就能随手收下任何语言的词或短语。回车追加，标签可选。词条按去掉首尾空白、统一 Unicode NFC 后的文本合并，保留大小写。

- 最近追加按词条的最后一次出现排序。出现最多按总次数排序，次数相同的词按最近追加时间排列。
- 标签随每次追加记录。一个词在任意一次追加时记了某个标签，筛选该标签就能找到它。
- 随机抽取从整个盒子中等概率选最多三个不同的词。

数据库每次追加保存原词、可选标签、记录时间和用于安全重试的请求 ID。次数和最近追加时间在读出后计算。词汇内容存在 `vocabulary_appends`，通过 `core/vocabulary.js` 访问。它使用 [Owner 专用迁移](../../db/2026-11-19-vocabulary.sql)，公开的 events 时间线和现有账户 JSON 导出均不包含词汇。
